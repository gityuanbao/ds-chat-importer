# DS 对话导入工具

**把 DeepSeek 网页端的历史对话，搬进 DeepSeek Harness，继续聊。**

这是一个运行在 [DeepSeek Harness（DSH）](https://deepseek.com/harness/) 中的第三方插件。读取 DeepSeek 导出的聊天记录后，它会把选中的对话创建为 DSH 工作区中的独立会话，方便查看和接续。

```text
DeepSeek 网页端 → 导出聊天记录 → DS 对话导入工具 → DSH 独立会话
```

[快速开始](#快速开始) · [使用方法](#使用方法) · [常见问题](#常见问题) · [详细安装与配置](INSTALL.md)

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 直接读取 ZIP | 支持 DeepSeek 导出包，也支持含 `chat_sessions/` 的已解压目录 |
| 搜索历史对话 | 按标题或会话 ID 筛选，查看日期、消息数和正文字符数 |
| 单条或批量导入 | 点击选择多条会话，也可以全选当前列表；显示逐条进度和结果 |
| 指定工作区 | 选择已有工作区或填写目标文件夹，必要时自动登记新工作区 |
| 接着历史对话聊 | 默认创建独立会话；也可通过 Agent 工具将历史内容放入当前上下文 |
| 清理重试噪声 | 默认去掉纯模板失败回复，并合并连续重复提问 |

## 快速开始

### 1. 准备 DSH 和聊天记录

- 安装并打开 [DeepSeek Harness](https://deepseek.com/harness/)，确认能使用插件管理页面。继续与模型对话还需要在 DSH 中配置可用的模型。
- 在 [DeepSeek 网页端](https://chat.deepseek.com/)的设置中找到数据导出，下载聊天记录 ZIP。插件不会代替你登录或抓取网页对话。
- 将原始导出包留作备份。插件处理的是其中的聊天记录格式，普通 ZIP、网页 HTML 或 Markdown 文件不能直接替代。

### 2. 下载并安装插件

1. 在本仓库点击 **Code → Download ZIP**，解压到一个固定位置。
2. 找到同时包含 `package.json`、`index.js` 和 `cordis.patch.yml` 的文件夹。GitHub 下载后通常叫 `ds-chat-importer-master`。
3. 在 DSH 打开 **插件 → 添加插件 → 安装第三方插件**，输入这个文件夹的**完整绝对路径**，完成安装并启用。不同版本的菜单名称可能略有差异；安装入口也可能在“设置 → 插件管理”。[官方安装说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.zh.md#安装一个组合包)
4. 完全退出并重新打开 DSH，在侧边栏找到 **DS 对话导入工具**。

例如，第 3 步填写的路径可以是：

```text
Windows：C:\DS-Tools\ds-chat-importer-master
macOS：/Users/你的用户名/DS-Tools/ds-chat-importer-master
Linux：/home/你的用户名/DS-Tools/ds-chat-importer-master
```

请替换为真实路径。安装后保留该文件夹，以便本地链接继续有效。插件的内部包名仍为 `@local/dsh-deepseek-archive`，插件管理页面可能同时显示它。

> **两个 ZIP 不要混淆：** 仓库 ZIP 是插件代码，需要先解压再安装；DeepSeek 导出的 ZIP 是聊天数据，在插件面板里打开即可。

### 3. 导入第一条对话

1. 打开插件面板，在 **档案来源** 中选择 DeepSeek 导出包；也可以粘贴 ZIP 或已解压目录的绝对路径，再点 **打开**。
2. 点击左侧的一条会话，使它处于选中状态。
3. 在右侧选择 **导入到哪个工作文件夹**。
4. 点击 **导入选中的 1 条**，等待结果。
5. 到侧边栏对应工作区打开新会话，再发送消息继续聊。若列表没有更新，刷新页面或重新打开 DSH。

## 使用方法

### 选择档案和批量导入

面板会在部分常用位置查找候选导出包。下拉列表里没有你的文件时，直接粘贴路径即可；已改名的 ZIP 也可以这样打开。

支持把 ZIP 拖进面板。拖入目录能否取得路径取决于宿主环境；若提示拿不到路径，改用 **选文件夹…** 或粘贴路径。

点击会话可以选中或取消选中；**全选**作用于当前显示的列表。筛选后，批量导入处理的是当前列表中选中的会话。一次导入超过 10 条时会再次确认，所有选中会话都会归入同一个目标工作区。

### 选择目标工作区

可以使用现有工作区、通过 **选择文件夹…** 选择目录，或直接填写绝对路径。未指定时，默认使用用户目录下的 `Documents/DeepSeek 导入`。

**工作区文件夹决定会话归属。** 实际会话日志写入 DSH 数据目录的 `sessions/`，通常是 `~/.dsh/sessions/`；设置了 `DSH_HOME` 时使用该目录。导入结果中会显示日志的实际路径。

### 通过 Agent 导入

先在插件面板里选好档案，然后在 DSH 对话中提出要求，例如：

```text
先列出标题含“旅行计划”的历史对话，确认后把指定的那一条导入为独立会话。
```

| 工具 | 用途 |
| --- | --- |
| `ds_archive_list` | 列出或搜索导出包中的会话 |
| `ds_archive_import` | 导入指定会话，默认创建独立会话 |
| `ds_archive_diag` | 查看宿主服务、会话列表与读回结果，辅助排查 |

`ds_archive_import` 用 `session` 指定会话 ID、ID 前缀或能唯一匹配的标题关键词。默认 `mode=session` 创建独立会话；设为 `mode=context` 可将历史内容放入当前上下文。更多参数见 [安装与配置指南](INSTALL.md#agent-工具参数)。

## 内容如何处理

- **对话分支：** 沿 `parent_id` 关系还原当前分支，不会把所有重新生成的回答一起铺开。
- **失败与重发：** 默认移除仅含模板回复的助手消息，合并相邻的相同用户提问；可通过 `keepFailures=true` 保留这些内容。
- **搜索和网页：** 保留查询词、结果数量或网页标题等简要标记，不重建网页快照或 DSH 工具调用记录。
- **附件与图片：** 保留文件名引用，不恢复附件文件或图片内容。
- **思考内容：** 独立会话不导入思考过程；上下文模式可通过 `includeThinking` 附带裁剪后的片段。
- **超长对话：** 独立会话模式不按字符预算压缩；上下文模式按“开头内容 + 中间提纲 + 尾部正文”组织内容，并在满足条件时尝试另存 Markdown。
- **重复导入：** 每次都会新建会话，当前没有自动去重或与已有会话合并的功能。

导出的文件由运行 DSH Host 的机器读取和处理。浏览器无法取得 ZIP 的本地路径时，会把文件传给当前连接的 DSH Host；如果 Host 部署在远程服务器，数据也会传到那台服务器。导入后的模型接续及宿主可能触发的标题生成，遵循 DSH 自身的模型与数据设置。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 安装后找不到插件入口 | 确认安装目录含 `package.json`，插件已启用，然后完全退出并重开 DSH |
| 提示找不到 `chat_sessions/` | 检查是否选中了 DeepSeek 聊天数据；若 ZIP 多套了一层目录，先解压，再选择直接包含 `chat_sessions/` 的目录 |
| 文件夹选择器打不开或拖入无效 | 在面板中直接填写绝对路径；远程 Host 需要能访问该路径 |
| 导入成功但侧边栏没有更新 | 刷新页面，检查目标工作区；仍异常时使用 `ds_archive_diag` 排查 |
| 显示“自检降级” | 已经写入，但宿主读回接口未能完整确认；先检查对应工作区，不要立即反复导入 |
| 导入后标题发生变化 | DSH 可能重新生成标题；可结合导入结果中的会话 ID 确认 |
| 提示 `zstdCompressSync` 不存在 | 运行插件的 Node.js 缺少该 API；更新 DSH 或其使用的运行时。要求见 [安装指南](INSTALL.md#运行环境) |
| 能否恢复网页端已删除、未导出的对话 | 只能处理导出包里实际存在的数据 |
| 卸载插件会删除已导入的会话吗 | 已导入的会话由 DSH 管理，插件没有随卸载删除它们的逻辑 |

DSH 的会话接口仍可能变化。本项目没有声明完整的宿主版本兼容范围；发布前检查了源码语法、包结构和文档，尚未完成真实 DSH 环境中的端到端导入验证。

## 项目结构与开发

```text
ds-chat-importer/
├── index.js          # Host：档案解析、会话导入、工具与同源接口
├── client.js         # Client：侧边栏面板和批量导入交互
├── cordis.patch.yml  # DSH 插件装配声明
├── package.json      # 包信息、导出与 DSH bundle 配置
├── locale/           # 中文、英文插件元信息
├── icon.svg          # 插件图标
├── INSTALL.md        # 安装、配置和打包说明
└── README.md
```

仓库提供可直接加载的 JavaScript，无需构建前端。开发检查与本地打包：

```bash
node --check index.js
node --check client.js
npm pack --dry-run --ignore-scripts
npm pack --ignore-scripts
```

`npm pack` 会生成 `local-dsh-deepseek-archive-0.2.0.tgz`，不会发布到 npm。上述检查不等于真实宿主集成测试，打包和配置细节见 [INSTALL.md](INSTALL.md)。

遇到问题可在 [Issues](https://github.com/gityuanbao/ds-chat-importer/issues) 中提供 DSH 版本、操作系统、操作步骤和已脱敏的错误信息；请勿提交完整私人聊天记录、导出包或密钥。
