# DS 对话导入工具

**把 DeepSeek 网页端聊过的内容，搬到 DeepSeek Harness 里接着聊。**

写到一半的文章、反复讨论的方案、积累很久的学习记录……把聊天记录导出后，用这个工具选中想保留的对话，就能在 DeepSeek Harness 中创建对应的新会话，打开后继续交流。

**[⬇ 下载插件](https://github.com/gityuanbao/ds-chat-importer/archive/refs/heads/master.zip)** · **[▶ 看视频教程](https://www.bilibili.com/video/BV1Mjsv61ERK/)** · [下载 DeepSeek Harness](https://deepseek.com/harness/)

这是安装在 **DeepSeek Harness（简称 DSH）** 里的第三方插件。开始前，请先安装 DSH；继续聊天还需要在 DSH 中配置可用的模型。

## 导入后能得到什么

- **一条历史对话，对应一条新会话。** 导入后出现在 DSH 侧边栏，方便找到并继续聊。
- **自己决定搬哪些。** 可以搜索标题，导入单条，也可以多选或全选当前列表。
- **按用途放到不同工作区。** 比如把写作讨论放进“内容创作”，把学习记录放进“学习笔记”。

**导出聊天记录 → 选中想搬的对话 → 导入 DSH → 打开新会话继续聊**

## 跟着做：第一次导入

### 第一步：从 DeepSeek 导出聊天记录

1. 打开 [DeepSeek 网页端](https://chat.deepseek.com/)，登录自己的账号。
2. 在设置中找到数据导出，按页面提示下载聊天记录。
3. 保存下载到的 **聊天记录 ZIP**，这个文件在导入时**不用手动解压**。

> 保留一份原始导出包，方便以后查找或重新导入。工具能搬运的内容，以导出包中实际包含的记录为准。

### 第二步：把插件装进 DSH

1. **[点击这里下载插件 ZIP](https://github.com/gityuanbao/ds-chat-importer/archive/refs/heads/master.zip)**，然后解压。
2. 打开解压后的 `ds-chat-importer-master` 文件夹，确认里面能直接看到 `package.json`、`index.js` 和 `cordis.patch.yml`。如果外面还套着一层文件夹，请继续打开到这一层。
3. 把这个文件夹放到固定位置，再复制它的**完整路径**。例如 Windows 下的 `C:\DS-Tools\ds-chat-importer-master`，请替换成你实际存放的位置。
4. 在 DSH 打开 **插件 → 添加插件 → 安装第三方插件**，在“包名或地址”中粘贴刚才的文件夹路径，完成安装并启用。
5. 完全退出并重新打开 DSH，侧边栏出现 **DS 对话导入工具**，就可以继续了。

不同 DSH 版本的菜单名称可能略有不同，入口也可能在 **设置 → 插件管理**。找不到时可以参考 [详细安装说明](INSTALL.md#从文件夹安装)。安装后请保留插件文件夹。

**这里有两个 ZIP，作用不同：**

| 你下载的文件 | 接下来怎么做 |
| --- | --- |
| 从本仓库下载的 **插件 ZIP** | **先解压**，在 DSH 中安装解压后的文件夹 |
| 从 DeepSeek 下载的 **聊天记录 ZIP** | **不用解压**，在插件面板里打开 |

### 第三步：选择对话并导入

1. 打开 **DS 对话导入工具**。
2. 在 **档案来源** 中选择刚才的聊天记录 ZIP。如果列表里没有，就把 ZIP 的完整路径粘贴到输入框，再点 **打开**；也可以尝试直接把 ZIP 拖进面板。
3. 在左侧找到想搬的对话，**点击选中**。第一次建议先选一条较短的对话试试。
4. 在右侧选择 **导入到哪个工作文件夹**。可以先用默认位置，也可以选自己已有的工作区。
5. 点击 **导入选中的 1 条**，等待显示导入结果。

“工作区”可以理解为 DSH 里整理会话的分组。默认位置是用户目录下的 `Documents/DeepSeek 导入`；选其他文件夹后，对话就归到对应的工作区里。

### 第四步：找到新会话，接着聊

回到 DSH 侧边栏，打开刚才选择的工作区，找到导入的会话。确认历史消息能看到后，发送一条新消息，例如：

> 我们继续刚才的讨论，帮我把下一步的方案写出来。

如果侧边栏没立即更新，先刷新页面或重新打开 DSH，再到对应工作区查看。

## 熟悉之后，可以这样用

| 想做什么 | 怎么操作 |
| --- | --- |
| 找到某段旧讨论 | 在面板搜索框输入标题关键词或会话 ID |
| 一次搬多条对话 | 点击选中多条，或点“全选”，再点击导入按钮；全选针对当前显示的列表 |
| 把不同主题分开放 | 分批导入，每批选择相应的工作区 |
| 换一个导出包 | 在“档案来源”中切换，或粘贴新文件的完整路径 |
| 使用已经解压的聊天记录 | 选择里面直接包含 `chat_sessions` 文件夹的那个目录 |
| 让 DSH 助手帮忙找和导入 | 先在面板选好档案，再让助手列出符合条件的历史对话；[进阶用法](INSTALL.md#agent-工具参数) |

批量导入会显示进度和每条结果。一次超过 10 条会再次确认，同一批会话都会进入你选定的工作区。

## 哪些内容会搬过去

| 内容 | 导入后的情况 |
| --- | --- |
| 当前对话分支中的文字问答 | 转成 DSH 会话，保留可读的问答内容 |
| “服务器繁忙”等失败占位和连续重复提问 | 默认清理，减少重复内容 |
| 联网搜索、打开网页的记录 | 保留查询词、数量或标题等简要提示 |
| 图片和附件 | 只保留文件名引用，**不会把文件本身搬过去** |
| 重新生成的其他回答分支 | 不会全部导入，仅还原当前分支 |
| 思考过程 | 默认独立会话不导入；进阶上下文模式可附带裁剪后的片段 |

**重复导入同一条历史对话，会再创建一条新会话。** 工具目前不会自动去重，也不会把它合并到已有会话中。

导入不会覆盖原始导出包；网页端已删除且没有导出的内容，也无法通过本工具恢复。导入后能否继续正常对话，还取决于 DSH 的模型配置及上下文容量。

## 卡住了，先看这里

| 遇到的情况 | 可以先这样处理 |
| --- | --- |
| 安装后找不到工具入口 | 确认选对了插件文件夹、已启用插件，再完全退出并重开 DSH |
| “档案来源”里没有聊天记录 | 直接粘贴聊天记录 ZIP 的完整路径，再点“打开” |
| 提示找不到 `chat_sessions` | 检查是否拿错了 ZIP；若导出包外面多套了一层目录，先解压，再选择直接包含 `chat_sessions` 的目录 |
| 拖入文件没反应，或文件夹选择器打不开 | 改用手动粘贴完整路径 |
| 显示导入成功，却找不到新会话 | 先检查导入时选择的工作区，再刷新页面 |
| 显示“自检降级” | 可能已经写入，但没有完整验证；先去工作区查看，避免反复导入出多份 |
| 导入后的标题变了 | DSH 可能重新生成标题，可以结合导入结果中的会话 ID 确认 |
| 能看到历史消息，但发不了新消息 | 先检查 DSH 中是否配置了可用模型，再查看 DSH 给出的错误提示 |

仍有问题，可以 [提交 Issue](https://github.com/gityuanbao/ds-chat-importer/issues)，写清楚“在哪一步卡住、用的 DSH 版本、系统、错误提示”。截图前请遮住私人对话、个人信息和密钥。

## 关于数据与兼容性

聊天记录交给你当前连接的 DSH 处理：DSH 在本机运行，数据就在本机处理；如果连接的是远程 DSH，拖入的 ZIP 可能会传到远程机器。继续聊天和 DSH 可能进行的标题生成，遵循 DSH 自身的模型与数据设置。

本项目没有覆盖所有 DSH 版本的兼容测试。已完成源码语法、包结构和文档检查，尚未完成完整的宿主端到端验证；首次使用请先导入一条短对话，确认能正常查看和接续后再批量操作。

需要配置默认目录、使用 Agent 工具、了解数据保存位置或自行打包，请看 **[安装与进阶说明](INSTALL.md)**。
